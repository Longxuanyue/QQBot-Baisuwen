# 隐私与数据说明

本文档说明白苏文（BaiSuWen）机器人在运行时收集、存储和传输哪些数据，以及你作为部署者应如何管理这些数据、如何告知你的用户。

> ⚠️ 本文档面向**部署者**（Bot 的主人）。本 Bot 具有记忆与画像能力，会长期存储用户数据，部署前请仔细阅读，并建议在用户可能接触到的渠道（群公告、README）注明本 Bot 的行为。

## 一、收集哪些数据

| 数据类型 | 收集方式 | 存储位置 |
|----------|----------|----------|
| 聊天文本 | 用户发送的消息（触发回复时） | 对话过程经 LLM 处理后生成记忆，原始消息本身**不落盘** |
| 语音消息 | 用户发送的 QQ 语音 | 由本地 Whisper 转文字后按文字处理，音频临时文件存于 `voice_cache/` |
| 图片 | 用户发送的图片（多模态开启时） | 下载缓存于 `image_cache/`，7 天自动清理；图片内容会发送给 LLM Vision API 理解 |
| 记忆 | 每次回复后由 LLM 后台提取 | `user_data/short_{uid}.db` / `long_{uid}.db` |
| 用户画像 | 从记忆库中规则提取（姓名/所在地/职业/喜好/关注话题） | 内存中构建并缓存，可随时由记忆库重新生成 |
| 订阅信息 | 用户主动订阅游戏新闻 | `game_data/game_news.db`（subscriptions 表） |
| 操作审计 | WebUI 管理操作 | `data/webui_audit.jsonl` |
| WebUI 用户角色 | 超管在 WebUI 配置 | `data/webui_users.json` |

**注意：不会收集的**——Bot 不读取用户的完整聊天记录，只在收到消息并触发回复时处理该条消息；群聊中未触发（概率未命中、冷却中、休眠中）的消息不会被处理。

## 二、数据流向第三方

| 场景 | 发送给谁 | 发送内容 |
|------|----------|----------|
| 对话 | DeepSeek API（或你配置的其他 OpenAI 兼容端点） | 消息文本、人设、相关记忆、用户画像摘要 |
| 记忆提取 | 同一 LLM 端点 | 最近的对话文本 |
| 图片理解 | 同一 LLM 端点（需 vision 模型） | 图片 base64 + 上下文 |
| 语音识别 | 无 | 纯本地 Whisper，音频不出本机 |

所有 LLM 请求均通过 `DEEPSEEK_API_BASE`（默认 `https://api.deepseek.com`）发送，传输走 HTTPS。**语音识别完全本地进行**，音频文件不发送给任何第三方。

## 三、数据存储位置

| 路径 | 内容 | git 状态 |
|------|------|----------|
| `user_data/` | 每用户短期/长期记忆库（`short_{uid}.db`、`long_{uid}.db`） | .gitignore 排除 |
| `data/` | WebUI 插件状态、审计日志、用户角色、备份、环境变量备份 | .gitignore 排除 |
| `game_data/` | 游戏新闻库（新闻/卡池/活动/订阅） | .gitignore 排除 |
| `voice_cache/` | TTS 合成音频、ASR 临时文件 | .gitignore 排除，随写入覆盖 |
| `image_cache/` | 图片缓存 | .gitignore 排除，每日 0:30 清理 7 天前文件 |
| `memory_backups/` | CLI 记忆备份 JSON | 由 CLI 工具生成 |

所有数据库均为本地 SQLite 文件，**不会自动上传**。仓库中仅提交 `.env.example` 模板，真实的 `.env`（含 API 密钥）被 .gitignore 排除。

## 四、数据保留与自动清理

记忆并非永久保存，由两套机制自动管理：

1. **遗忘曲线（幂律衰减）**：记忆权重随距上次访问时间的增长按幂律衰减，低于 `MEMORY_WEIGHT_THRESHOLD`（默认 0.1）时被清理。
2. **容量上限**：短期库默认最多 2000 条、长期库 5000 条，超出清理最旧/低权重记忆。

每天 02:00 执行维护任务（合并相似记忆、短期→长期升级、清理弱记忆）。参数均可通过 `.env` 调整，详见 [configuration.md](configuration.md)。

## 五、手动管理与删除

| 操作 | 方式 |
|------|------|
| 查看记忆 | WebUI 记忆页，或 `python tools/view_memory.py` / `python tools/memory_cli.py list <QQ号>` |
| 搜索记忆 | WebUI 记忆页搜索框，或 `python tools/memory_cli.py search <QQ号> <关键词>` |
| 删除单条 | WebUI 记忆页删除按钮（识别短/长库并加前缀防误删） |
| 清空用户记忆 | WebUI 记忆页「清空」 |
| 备份/恢复 | WebUI 备份页（可选包含记忆库），或 `python tools/memory_cli.py backup <QQ号>` |
| 删除全部用户数据 | 停止 Bot，删除 `user_data/` 目录后重启 |

## 六、安全措施

- **密钥保护**：`.env` 不提交到 git，模板 `.env.example` 中无真实密钥
- **WebUI 认证**：登录需在 QQ 中通过 `/auth <token>` 完成，session 带 HMAC 签名，24 小时过期；重启后密钥重新生成，旧会话全部失效
- **权限分级**：WebUI 分 super / admin / user 三级，敏感操作（审计、用户管理）仅 super 可用
- **SSRF 防护**：图片/语音下载校验 URL 目标地址，拒绝内网/保留地址；文件名基于 URL 哈希生成，防路径穿越
- **审计日志**：WebUI 的所有配置修改、记忆删除、恢复操作均记录于 `data/webui_audit.jsonl`
- **备份防误覆盖**：恢复备份前自动将现有文件备份到 `data/env_backups/`

## 七、部署者的责任

1. **告知用户**：若 Bot 加入他人所在的群，建议在群公告或简介中说明「本机器人会记住聊天内容用于提供个性化陪伴，可随时要求删除」。
2. **管理数据**：定期通过 WebUI 或 CLI 检查记忆库；不再使用的用户数据建议删除。
3. **保护本机**：`HOST` 保持 `127.0.0.1`（默认），如必须开放公网请使用反向代理 + HTTPS，并留意 WebUI 的暴露面。
4. **API 密钥安全**：`DEEPSEEK_API_KEY` 仅在 `.env` 中配置，切勿提交到仓库或分享。
5. **合规**：请遵守所在地区法律法规及 QQ 平台关于机器人的使用规范。本 Bot 的对话内容由大模型生成，可能包含不准确信息，不应用于医疗、法律等专业场景的建议。
